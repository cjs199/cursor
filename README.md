# BTC 购买方案生成器

基于从 Google Finance 抓下来的两份 BTC/USD 历史价格序列, 自动生成
"核心仓 + 5 档阶梯抄底 + 止盈/止损 + 时点提示" 的购买方案.

## 数据

* `data/btc_prices.json` — 30 分钟级 K 线 (近 ~4 天).
* `data/btc_prices_monthly.json` — 约 1 个月的日级采样.

两份数据均直接来自 Google Finance Wholepage Chart 的内部 JSON
(已剥掉外层 HTML/SVG 渲染部分, 只保留价格和时间戳).

## 用法

```bash
python3 plan.py                      # 默认预算 10,000 USD, 文本输出
python3 plan.py --budget 5000        # 自定义预算
python3 plan.py --json               # 输出原始 JSON, 便于后续脚本接管
```

## 策略概述

1. 用月线序列取近月最高/最低/均价, 算出现价在区间中的百分位.
2. 按百分位决定核心仓与阶梯仓的资金分配:

   | 现价分位 | 核心仓 | 阶梯抄底 | 含义 |
   | --- | --- | --- | --- |
   | < 25%  | 60% | 40% | 区间低位, 重仓核心 |
   | 25–75% | 40% | 60% | 区间中位, 平衡 |
   | > 75%  | 25% | 75% | 区间高位, 留更多子弹 |

3. 阶梯单按现价向下打 **3 档** (−1.5%, −4%, −7%),
   单档资金递增 (1× / 1.5× / 2.5×), 越跌买越多.
   浅档贴近现价以提高成交概率, 深档放在月内低位附近备深跌.
4. 止盈位 = 月内最高价 × 1.02; 止损位 = 月内最低价 × 0.97.
5. 用最近 1 小时收益率给出"立即下单 / 等待回踩 / 按计划"三种时点提示.
